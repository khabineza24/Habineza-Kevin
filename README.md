# K VIBZ — Habineza Kevin's E-Portfolio

A personal portfolio website: music, skills, projects and contact.
Built with plain HTML, CSS and JavaScript (no frameworks, nothing to install).

## Pages
| Page | File |
|---|---|
| Welcome | `index.html` |
| Home | `home.html` |
| About | `about.html` |
| Skills | `skills.html` |
| Portfolio (music player + projects) | `portfolio.html` |
| Contact | `contact.html` |

## Files
- `styles.css`, `script.js` — shared by every page
- `chatbox.css`, `chatbox.js` — the chat assistant
- `extras.css`, `extras.js` — intro screen and surprise effects
- `config.js` — **your WhatsApp, email and Instagram (edit this first)**
- `home.*`, `about.css`, `skills.*`, `portfolio.*`, `contact.*` — page-specific files
- `images/`, `audio/`, `files/` — your photos, music and CV (see the README.txt inside each)

## Before you publish
1. Open `config.js` and add your WhatsApp number, email and Instagram.
2. Add your photos to `images/`, your music to `audio/` and your CV to `files/`.
3. Edit the text on each page so it describes you and your real projects.

## Publish with GitHub Pages
1. Create a repository and upload **all** these files (keep the folders).
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

File names are case-sensitive on GitHub: `Kevin.jpg` and `kevin.jpg` are different files.
